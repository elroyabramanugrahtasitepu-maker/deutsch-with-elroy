# Deutsch with Elroy

An interactive language learning platform designed to help users learn German, English, and Japanese through structured lessons, exercises, quizzes, and educational games.

## Overview

Deutsch with Elroy is an educational web platform that provides language learning materials in an interactive and engaging format.

The platform supports multiple languages and combines learning materials with exercises, quizzes, and games to make the learning process more interactive.

## Languages

- German
- English
- Japanese

## Features

- Language learning materials
- Structured lessons
- Exercises and practice questions
- Quizzes
- Educational games
- Interactive learning activities
- Multi-language learning content
- Progress-oriented learning experience

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Project Purpose

This project was developed as a web-based educational platform to provide accessible and interactive language learning resources for learners interested in German, English, and Japanese.
